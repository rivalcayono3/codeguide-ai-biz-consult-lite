# CodeGuide AI Biz Consult Lite App Flow Document

## Onboarding and Sign-In/Sign-Up

When a new user arrives at the application, they first land on a public home page that introduces the purpose of the AI Business Consultation platform and invites them to sign up or sign in. The sign-up process begins when the user clicks on the sign-up button, which opens Clerk’s authentication widget. From here, the user can choose to register using their email and a password or leverage social logins such as Google or GitHub. Clerk handles the account creation behind the scenes, sending a verification email if required and establishing a secure session once the user confirms their address. If the user forgets their password, they can click a “Forgot password” link in the sign-in form, prompting Clerk to send a reset link via email. Once the password is reset, the user is returned to the sign-in form to authenticate again. Signing out is as simple as clicking the user avatar in the top navigation and selecting the sign-out option, which ends the Clerk session and returns the user to the public landing page.

## Main Dashboard or Home Page

After signing in, the user is redirected to the main dashboard at the `/dashboard` route. The dashboard displays a left-hand navigation bar with links to core sections such as New Analysis, My Reports, Coaching Sessions, and Settings. At the top of the page, a header shows the user’s name, subscription status, and an avatar menu for signing out or accessing account preferences. The center area of the dashboard features an overview widget that summarizes recent report generation activity, indicates processing jobs in progress, and highlights premium features available to subscribers. From this dashboard view, users can click “Start New Analysis” to begin a new consultation or select “View Reports” to see a list of past AI-generated reports.

## Detailed Feature Flows and Page Transitions

When the user chooses to start a new analysis, they are taken to the `/new-analysis` page, which presents a multi-field dynamic form built with shadcn/ui components. Each input field captures structured business data such as company details, target goals, and financial information. As the user completes sections of the form, real-time validation ensures all required fields are correctly filled. Upon clicking the “Generate Report” button, the frontend sends the collected data to the `/api/chat/route` API endpoint. In that endpoint, the application saves the inputs to the Supabase `business_inputs` table, constructs a prompt for the OpenAI or Anthropic model, and dispatches the AI call via the Vercel AI SDK. The route immediately returns a processing status, and the user is redirected back to the My Reports list where a new “Processing” entry appears. The client then polls Supabase or listens for Realtime updates to detect when the report is complete.

Once the AI content is fully generated, the report status changes to “Complete” in the My Reports list. The user can click on the report title to navigate to `/report/[id]`, where a detailed multi-section report is displayed using tabbed panes and accordions. Each section covers topics like market analysis, revenue projections, and strategic recommendations. If the user has admin or expert privileges assigned via Clerk metadata, they can instead access the `/expert-review` route to see a queue of all pending reports across users, review content, add comments, and publish feedback. Premium users also have access to a dedicated financial dashboard at `/dashboard/premium` that visualizes data with charts and graphs, illustrating key metrics extracted from their reports.

## Settings and Account Management

The Settings section at `/settings` allows users to manage their personal profile information, change their display name, and update notification preferences. A theme toggle enables light or dark mode, while contact information can be edited directly in the profile form. For users on subscription plans, a Billing tab displays current plan details and payment history by integrating with Stripe. From here, subscribers can upgrade or downgrade their plan, add or remove payment methods, and view upcoming invoices. When changes are saved, the application calls the relevant Stripe APIs server-side and updates the Supabase `users` table with the new subscription status. After completing any settings update, the user can click “Back to Dashboard” to return to the main application flow.

## Error States and Alternate Paths

If the user enters invalid data in any form field, inline validation highlights the error and displays a clear message explaining the issue. Should the AI report generation API fail due to a network timeout or model error, the API route catches the exception, marks the report record with a “failed” status, and returns an error code. The My Reports list shows a red error icon next to failed entries, and hovering or clicking reveals the error message with an option to retry generation. In cases of lost connectivity, the app displays a full-screen banner alerting the user to check their internet connection and automatically attempts to reconnect. If a non-authenticated user attempts to access protected pages such as `/dashboard` or `/new-analysis`, the middleware redirects them back to the sign-in page with a prompt to log in.

## Conclusion and Overall App Journey

From the moment a new user discovers the platform on the public landing page to signing up via Clerk, the application guides them smoothly into generating AI-powered business consultation reports. The main dashboard serves as the hub for launching new analyses and reviewing past work. Each feature flow, from the input form to the AI backend and final report viewer, is connected by clear page transitions and real-time status updates. Account settings and billing management live in a separate section but remain just a click away. Error handling and recovery paths ensure users can quickly fix mistakes or retry failed operations. This comprehensive journey supports both casual standard users and advanced premium subscribers, providing a solid foundation for everyday business consultation powered by AI.
